# Clinic Ideas

Double-click `Start Clinic Ideas.command` to launch the app in your browser.

Or run this in a terminal from this folder:

```sh
python3 server.py
```

Then open http://127.0.0.1:8765. `index.html` is the visual front end, but it requires the local Python app because the insight database, history, and weighted random selection are persistent SQLite features.
